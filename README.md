# Unpoly Demo

This is the server code for the [Unpoly](https://unpoly.com) demo app.

The demo application is implemented in Ruby on Rails, but you can use Unpoly with any backend that renders HTML on the server.

You can find a live deployment of this app at [demo.unpoly.com](https://demo.unpoly.com/).

## Alternative implementations

Community members have reimplemented this demo in various languages and frameworks:

- [Python / Django](https://github.com/spapas/django-unpoly-demo)
- [PHP / Laravel](https://github.com/adamkiss/unpoly-demo-laravel)
